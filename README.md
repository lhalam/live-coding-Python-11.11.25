## Про проєкт

Невеликий Flask застосунок для створення, перегляду, завантаження та редагування текстових нотаток (.txt). Нотатки зберігаються як файли у директорії `uploads/`.

Основні можливості:
- 📄 Список наявних нотаток на головній сторінці (`/`).
- ✍️ Створення нової нотатки (`/create_note`).
- 🖊️ Редагування існуючої нотатки (`/update_note/<filename>`).
- ⬇️ Завантаження файлів нотаток (`/uploads/<filename>`).

Обмеження:
- Підтримуються лише файли з розширенням `.txt`.
- Під час редагування змінюється лише вміст файлу; перейменування файлу (зміна заголовка) не виконується.

## Стек і залежності

- Python (рекомендовано 3.10+)
- Flask 3.x
- Jinja2 (шаблони)

Залежності визначено у `requirements.txt`.

## Швидкий старт (Windows, PowerShell)

1) Створіть та активуйте віртуальне середовище

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2) Встановіть залежності

```powershell
pip install -r requirements.txt
```

3) Запустіть застосунок

```powershell
python .\app.py
```

За замовчуванням сервер стартує у режимі debug на `http://127.0.0.1:5000/` (хост: 0.0.0.0, порт: 5000).

## Використання

1) Відкрийте у браузері `http://127.0.0.1:5000/` — побачите список файлів у `uploads/`.
2) Натисніть «Створити нотатку», заповніть «Заголовок» і «Текст нотатки» та збережіть.
3) Щоб завантажити файл — клікніть на назву файлу в списку.
4) Щоб відредагувати — натисніть «Редагувати» біля потрібної нотатки.

Примітка: під час редагування змінюється вміст існуючого `.txt`-файлу; ім'я файлу не змінюється.

## Структура проєкту

```
app.py                # Flask застосунок і маршрути
requirements.txt      # Пакети Python
templates/
	create_note.html    # Форма створення/редагування нотатки
	file_list.html      # Список файлів/нотаток
uploads/              # Каталог збережених .txt нотаток (створюється автоматично)
```

## Налаштування

- Коренева директорія для файлів: `uploads/` (див. константу `UPLOAD_FOLDER` у `app.py`).
- Параметри запуску визначено в `app.run(...)` у `app.py` (debug, host, port). За потреби змініть їх у коді або використайте власний скрипт запуску.

## Типові питання/проблеми

- Порожній список на головній: створіть першу нотатку — каталог `uploads/` і файли з'являться автоматично.
- 404 при редагуванні вручну через URL: шлях очікує ім'я файлу без розширення `.txt` (UI-лінк «Редагувати» формує корректне посилання автоматично).
- Інші формати файлів не відображаються: застосунок фільтрує лише `.txt`.
